# 📊 Dynamic Excel Dashboards Showcase

A curated portfolio of 7 interactive, business-driven Excel dashboards. These projects demonstrate advanced data analysis, automated reporting, and decision-support systems designed for real-world operational challenges.

⚠️ **Note on Data Privacy & File Integrity:** Due to the sensitivity and proprietary nature of the business data, the original operational files have not been uploaded to this repository. Furthermore, the dataset displayed in the dashboard has been partially blended with synthetic/dummy values to protect confidentiality while fully demonstrating the dashboard's architecture, logic, and dynamic analytical capabilities.

## 🛠️ Technical Stack & Methodology

*   **Data Integration (ETL):** Power Query (M Language) for automated data cleaning, merging, and transformation.
*   **Data Modeling:** Power Pivot & DAX (Data Analysis Expressions) to establish robust Star-Schema relationships.
*   **Interactivity:** Form Controls, Timeline Slicers, and advanced Dynamic Array formulas (XLOOKUP, FILTER, LET, LAMBDA).
*   **Visualization Design:** Bullet graphs, Pareto charts, Gauge charts, and custom KPI Scorecards aimed at "At-a-Glance" decision-making.

## 💡 Philosophy of Design

*   **Automation:** Minimize manual entry; emphasize "Refresh-Only" workflows.
*   **Scalability:** Use table-based structures that grow seamlessly as underlying data expands.
*   **Clarity:** Prioritize user-centric design—providing actionable insights rather than just raw numbers.
